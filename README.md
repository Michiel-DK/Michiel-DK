## Start here

- **[wilco](https://github.com/Michiel-DK/wilco)**: an eval suite for local models. You write the exam for your own
  task, every model sits it and the cheapest one that passes wins. `wilco check` re-sits the exam after a model or
  runtime update. 8 office tasks, 310 cases, graded by code, no LLM judge.
- **[pierre](https://github.com/Michiel-DK/pierre)**: a Claude tool-use agent over 11 tools, also served over MCP.
  Code runs a claim auditor over the tool results and sends fabricated claims back for repair. Graded by wilco on 21
  cases of invented data, plus a slice of AgentDojo so it is also tested on cases I did not write.
- **[dev-harness-public](https://github.com/Michiel-DK/dev-harness-public)**: the weekly scorecard of the harness my
  coding agents work through: what merged, what it cost, what the review gate caught. 1,112 merges in 17 weeks.
